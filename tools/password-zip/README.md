# Password ZIP acceptance tools

Use the installed Node 24/npm environment. No extra dependency/browser download.

- `node tools/password-zip/generate-fixtures.mjs`: deliberately regenerate the 16
  tiny committed fixtures using installed 7-Zip (default Windows path, override
  `SEVEN_ZIP`) plus pinned zip.js 2.23.0. Review fixture/manifest changes. Encrypted
  salt/timestamps can make regenerated bytes differ. All credentials are public
  **TEST FIXTURE ONLY**: `aniview-test`, or `beta` for the second different-secret
  entry. No personal secrets/media may be used in committed fixtures.
- `npm run build`, then `node tools/password-zip/preview.mjs --port 4280` serves
  `/AniView/` from dist and an explicit sample whitelist under
  `/AniView/validation/password-zip/`. GET/HEAD only; no upload/write API. It binds
  localhost by default. `--root <frozen build>` supports a stable acceptance build.
  Samples remain outside dist and are never part of production Pages artifacts.
- `node tools/password-zip/run-browser.mjs` runs installed Edge against that
  preview. Override `ANIVIEW_PASSWORD_URL` for another `/AniView/` origin. Output
  is ignored under `.tools/m10b2/`: nine grouped production UI checks, independent
  fixtures, input/keyboard/locale, corruption, stale/cancel/close/replacement,
  encrypted conversion/Back, privacy, ownership and viewport screenshots. Test-only
  delayed Worker delivery does not modify product code or log credentials.

Fresh Android procedure and gate:
[`milestone-m10b2-android-validation.md`](../../docs/milestones/milestone-m10b2-android-validation.md).
Do not infer phone results from these desktop tools.
