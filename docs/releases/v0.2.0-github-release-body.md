# AniView v0.2.0

Create GIF animations from static JPEG/PNG/WebP images, convert between GIF,
Animated WebP and APNG, export animations to H.264 MP4, and convert supported
MP4/H.264 or WebM/VP9 videos to animated images. All media processing stays local.

- Shared image viewer with playback, frame inspection, zoom/pan and ZIP browsing.
- English / 简体中文 UI; switching languages preserves the workspace.
- Preview/Back, distinct download names, cancellation and bounded Worker handoff.
- Desktop Edge and real Android Edge/Quark validation; 1,001 automated tests.

Creator generates GIF only; save/reopen it for WebP/APNG conversion. Video input
is limited to 8-bit SDR opaque H.264/VP9 profile 0; audio is ignored. MP4 export
is lossy, silent, one-cycle, with transparency on white. Video conversion requires
a secure context and usable browser/OS codec support, with 150 sampled frames,
30-second selection and 720-pixel output long-side limits plus workload guards.
Password ZIP, RAR/7z, advanced editing and custom FPS/resolution are deferred.

No app-observable resource leaks were detected in validated flows; native/GPU
memory is not fully observable. The 12 moderate audit findings are development
lint/configuration dependencies; production dependency audit is zero.

AniView's code remains UNLICENSED. Third-party licenses, including unmodified
Mediabunny 1.65.0 / MPL-2.0 source availability, remain applicable.
