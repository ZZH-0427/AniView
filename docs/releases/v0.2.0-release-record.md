## Limitations, deferred work and rollback

Creator generates GIF only. Video support is limited to the documented secure
context, codec/profile/SDR/opaque and workload constraints; no audio. H.264 export
is lossy, one cycle and white-composited alpha. Workspaces do not survive full
reload; download location/gallery indexing is browser-controlled. See the
[release notes](v0.2.0.md) and [README](../../README.md) for all limits.

Direct multi-target image creation, password ZIP UI, RAR/7z, advanced editing,
custom FPS/resolution and additional languages remain deferred.

Rollback was not needed or executed. The [preparation plan](v0.2.0-release-preparation.md)
retains the safe new-main-commit restoration of v0.1.0 and redeployment workflow;
tag refs must never be force-moved. This post-release archive is committed only
to retained `release/v0.2.0`, so it does not retrigger Pages or change the immutable
main release/tag target. Its branch HEAD is a documentation archive, not a new RC.
