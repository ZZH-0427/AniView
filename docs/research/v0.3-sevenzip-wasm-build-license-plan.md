  `d06cf3c4b4cb085f9a9a5c385b80e46d9ab47849860a4e2c00e1882409c7f830`;
  wrapper `6b0caee34dca8d9dffcc53ab26e9c95a8c6ae5ff5f15f309ad8b73f009487ba8`.

`spikes/rar-7z/prepare.mjs` pins/downloads/verifies those sources. Build selects
upstream source object lists, constructs only7z/RAR/RAR5 native indexed handlers
and uses Z7_ST / Z7_EXTRACT_ONLY. There is no CLI main, general archive factory,
creation/update/delete/SFX API. Decode translation units are retained
conservatively; this is not a claim that every unrelated codec was stripped.
COPY, LZMA, LZMA2, Deflate, BZip2, PPMd, BCJ, BCJ2 and Delta fixture hashes pass.

The source portability patch adds an Emscripten branch to Windows/System.cpp's
GetRamSize, as in the pinned wrapper. Our bridge adds indexed property getters,
selected bounded output and typed outcomes. No handwritten compression codec.
The complete actual source list, flags and commands are generated in ignored
work/commands.json and build.ninja; the generation recipe is committed.

Key flags: -Oz, -fexceptions, --no-entry, MODULARIZE, EXPORT_ES6,
ENVIRONMENT=worker,node, INITIAL_MEMORY=16777216, MAXIMUM_MEMORY=67108864,
ALLOW_MEMORY_GROWTH=1, STACK_SIZE=1048576, ABORTING_MALLOC=0,
DYNAMIC_EXECUTION=0, WORKERFS. No threads, SharedArrayBuffer, memory64, Asyncify,
COOP/COEP or script unsafe-eval required by the tested component.

## Distribution prototype

`spikes/rar-7z/THIRD_PARTY_NOTICES.md` and `licenses/` retain the complete engine,
LGPL/unRAR/BSD notices, wrapper LICENSE and Emscripten/system-library notices.
The isolated page links an exact-version/hash manifest and a downloadable
corresponding-source archive (~3.5 MiB), assembled before phone handoff. It
contains pinned original engine/wrapper source archives, native adapter/build
source, portability-change recipe and full notices. No large upstream source
tree is committed to AniView. Full upstream source notices remain intact.

The component is separate replaceable JS/WASM, with no runtime hash lock blocking
modified builds. Library-derived component modifications are supplied under the
applicable LGPL-2.1-or-later/unRAR terms as stated in its notices; this does not
select/relicense AniView itself. Preserve restriction notices: RAR decompression
code must not be used to recreate a RAR-compatible compressor. No RAR-writing
work is present or approved.

Future formal distribution must retain corresponding source for each shipped
binary, including changes/build recipe and applicable linked library source and
notices, and verify the chosen LGPL replacement/relinking compliance route. A
Worker boundary, private:true or homepage link alone is not compliance. The
prototype package is concrete engineering evidence, not legal clearance.

## Deployment and source loading

All paths are relative to import.meta.url under /AniView/. Engine downloads are
local assets, lazy after OPEN, not runtime npm/CDN requests. The frozen page uses
static production files, no Vite/HMR. CSP permits wasm-unsafe-eval but not script
unsafe-eval; no blob Worker needed. Home/ZIP product cannot load this component:
normal source/build imports have no reference, and root build contains no spike
assets. The accepted zip.js2.23.0 path is untouched.

Temporary HTTPS testing serves code and public fixtures only. File contents,
passwords and private filenames are never uploaded or logged. The generated
source package must be regenerated if library code/build inputs change.
