# Viewer acceptance samples

Original CC0-1.0 test artwork generated by `tools/static/generate-fixtures.mjs`
and `tools/viewer/generate-fixtures.mjs`; no user media or downloaded artwork.

- `mixed-media.zip`: JPEG, GIF, PNG, APNG, static WebP, animated WebP in that order.
- `long.webp`: 200 alternating original red/green frames for backward inspection.
- `orientation-6.jpg`: original colored quadrants with EXIF orientation 6; normal
  viewing dimensions are 20×40 rather than the stored 40×20 pixels.

These are deliberate small public acceptance assets, not conversion/export features.
